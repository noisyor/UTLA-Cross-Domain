This folder is intentionally empty in the lightweight repository.

For `ASCADV1_to_ASCAD_Transfer_UTLA.py`, place extracted ASCAD fixed-key NumPy files under one of:

```text
Data/ASCAD/
Data/ASCAD_desync50/
Data/ASCAD_desync100/
```

Each directory should contain `X_train.npy`, `Y_train.npy`, `X_attack.npy`, `Y_attack.npy`, `plaintexts_train.npy`, and `plaintexts_attack.npy`.
