Core workflow

Four steps from data to key rank.

Run experiment scripts from inside their dataset directory so the documented relative paths resolve correctly.

01

Download

Place each public dataset in the Data path described by its local README.

02

Profile

Train the encoder and classifier using labeled source traces.

03

Adapt

Train the target encoder using unlabeled target traces.

04

Evaluate

Measure the target trace count needed to reach GE=1.

Quick start

Install, profile, and transfer.

The example below runs a SAKURA-AES source model and transfers it to XMEGA power traces.

1. Install dependencies$ pip install -r requirements.txt
2. Profile the source model$ python Source_Profiling.py 1 1
3. Run cross-domain UTLA$ python UTLA_from_Sakura_to_XMEGA-Power.py 1 1 2
